## Technical Standards

### Languages and Frameworks
- **Frontend**: Vue 3, Pinia for state management, Tailwind CSS + PrimeVue for UI styling.
- **Backend**: ASP.NET Core (.NET 10) with isolated relational databases per microservice.

### Testing Requirements
- Playwright for .NET for end-to-end and UI testing.

### Performance and Scale
- The public event catalogue must query ~10,000 events in < 1s at p95.
- API Gateway endpoints must respond in < 200ms at p95.
- The message broker must gracefully absorb bursts of 500+ concurrent events.

### Deployment and Constraints
- Docker-only containerization, targeting Kubernetes.

### Resilience
- All cross-service communication requires structured correlation IDs and exponential backoff retries.

### Compliance Validation

should be flagged and addressed before merge.

### Exception Handling
